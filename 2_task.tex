\section{Режекторный полосовой фильтр}

Перейдем ко второму заданию, в рамках которого необходимо проанализировать работу режекторного фильтра. В отличие от фильтра нижних частот, который подавляет все частоты выше частоты среза, режекторный фильтр предназначен для подавления сигнала в узкой полосе вокруг некоторой частоты $\omega_0$, пропуская при этом как более низкие, так и более высокие частоты.

Согласно заданию, мы рассматриваем динамический фильтр второго порядка со следующей передаточной функцией:

\begin{equation*}
    W_2(p) = \frac{p^2 + a_1p + a_2}{p^2 + b_1p + b_2}
\end{equation*}

где $a_1, a_2, b_1, b_2$ являются вещественными параметрами, которые нам предстоит определить. Для их нахождения воспользуемся условиями, приведенными в задании.


\subsection{Определение параметров фильтра}

Получим общее выражение для амплитудно частотной характеристики фильтра.

\paragraph{Общий вид АЧХ}
\begin{equation*}
    W_2(i\omega) = \frac{(i\omega)^2 + a_1(i\omega) + a_2}{(i\omega)^2 + b_1(i\omega) + b_2} = \frac{(a_2 - \omega^2) + i(a_1\omega)}{(b_2 - \omega^2) + i(b_1\omega)}
\end{equation*}
\begin{equation*}
    |W_2(i\omega)| = \frac{|(a_2 - \omega^2) + i(a_1\omega)|}{|(b_2 - \omega^2) + i(b_1\omega)|}
\end{equation*}
\begin{equation*}
    |W_2(i\omega)| = \frac{\sqrt{(a_2 - \omega^2)^2 + (a_1\omega)^2}}{\sqrt{(b_2 - \omega^2)^2 + (b_1\omega)^2}}
\end{equation*}

\paragraph{1. Условие равенства АЧХ нулю}
Согласно заданию, для некоторой частоты $\omega_0$ АЧХ фильтра должна быть равна нулю. Дробь АЧХ фильтра равна нулю только тогда, когда её числитель равен нулю:
\begin{equation*}
    \sqrt{(a_2 - \omega_0^2)^2 + (a_1\omega_0)^2} = 0
\end{equation*}
Корень из суммы двух неотрицательных слагаемых равен нулю только в том случае, если каждое слагаемое равно нулю. Это дает нам систему из двух уравнений:
\begin{itemize}
    \item $(a_2 - \omega_0^2)^2 = 0 \implies a_2 = \omega_0^2$
    \item $(a_1\omega_0)^2 = 0 \implies a_1 = 0$ (поскольку $\omega_0$ это конкретная частота, она не равна нулю).
\end{itemize}
Таким образом, мы определили два параметра числителя: $a_1 = 0$ и $a_2 = \omega_0^2$.

\paragraph{2. Условие для крайних частот}
Фильтр должен пропускать сигналы на очень низких и очень высоких частотах, то есть его АЧХ должна стремиться к единице при $\omega \to 0$ и $\omega \to \infty$. Подставим уже найденные $a_1=0$ и $a_2=\omega_0^2$ в общую формулу АЧХ:
\begin{equation*}
    |W_2(i\omega)| = \frac{\sqrt{(\omega_0^2 - \omega^2)^2}}{\sqrt{(b_2 - \omega^2)^2 + (b_1\omega)^2}} = \frac{|\omega_0^2 - \omega^2|}{\sqrt{(b_2 - \omega^2)^2 + (b_1\omega)^2}}
\end{equation*}
Теперь проверим пределы. При $\omega \to 0$:
\begin{equation*}
    \lim_{\omega \to 0} |W_2(i\omega)| = \frac{|\omega_0^2 - 0^2|}{\sqrt{(b_2 - 0^2)^2 + (b_1 \cdot 0)^2}} = \frac{\omega_0^2}{\sqrt{b_2^2}} = \frac{\omega_0^2}{|b_2|}
\end{equation*}
По условию этот предел должен быть равен 1, следовательно, $|b_2| = \omega_0^2$. Выберем положительное значение $b_2 = \omega_0^2$.
Далее проверим предел при $\omega \to \infty$.
\begin{equation*}
    \lim_{\omega \to \infty} \frac{|\omega_0^2 - \omega^2|}{\sqrt{(\omega^2(\frac{b_2}{\omega^2} - 1))^2 + \omega^2 b_1^2}} = \lim_{\omega \to \infty} \frac{\omega^2|\frac{\omega_0^2}{\omega^2} - 1|}{\omega^2\sqrt{(\frac{b_2}{\omega^2} - 1)^2 + \frac{b_1^2}{\omega^2}}} = \frac{|0-1|}{\sqrt{(0-1)^2+0}} = 1
\end{equation*}
Этот предел равен единице и выполняется автоматически при найденных параметрах.

\paragraph{3. Условие устойчивости}
Фильтр должен быть устойчивым. Это означает, что корни полинома знаменателя $p^2 + b_1p + b_2$ должны иметь строго отрицательную вещественную часть. Это эквивалентно требованию положительности всех его коэффициентов. Мы уже нашли, что $b_2 = \omega_0^2$, и так как $\omega_0$ это реальная частота, то $\omega_0^2 > 0$. Следовательно, для устойчивости остается единственное условие: $b_1 > 0$.

\paragraph{Итоговая передаточная функция}

Собрав все найденные соотношения ($a_1=0, a_2=\omega_0^2, b_2=\omega_0^2, b_1>0$), мы получаем итоговый вид передаточной функции режекторного фильтра:

\begin{equation*}
    W_2(p) = \frac{p^2 + \omega_0^2}{p^2 + b_1p + \omega_0^2}
\end{equation*}
Здесь $\omega_0$ это частота, которую фильтр будет подавлять, а параметр $b_1 > 0$ определяет ширину и качество этой режекции. Для дальнейших исследований выберем начальное значение $b_1 = 1$.


\subsection{АЧХ режекторного фильтра}
Перейдём к анализу частотных свойств спроектированного режекторного фильтра. Как было показано выше, итоговая передаточная функция имеет вид:
\begin{equation*}
    W_2(p) = \frac{p^2 + \omega_0^2}{p^2 + b_1p + \omega_0^2},
\end{equation*}

Соответствующая амплитудно-частотная характеристика записывается как:
\begin{equation*}
    |W_2(i\omega)| = \frac{|\omega_0^2 - \omega^2|}{\sqrt{(\omega_0^2 - \omega^2)^2 + (b_1\omega)^2}}.
\end{equation*}
Для исследования влияния параметра $b_1$ на форму АЧХ был построен сравнительный график для набора значений $b_1 \in \{0.1, 0.5, 1.0, 2.0, 5.0, 10.0\}$ в диапазоне частот $\omega \in [0, 50]$ рад/с.

    \caption{АЧХ режекторного фильтра $|W_2(i\omega)|$ при различных значениях параметра $b_1$ ($\omega_0 = 5$ рад/с)}
    \label{fig:afc_b1_comparison}
\end{figure}

Анализ графика, представленного на рисунке~\ref{fig:afc_b1_comparison}, позволяет сделать следующие выводы о поведении АЧХ.

Во-первых, для всех рассмотренных значений $b_1$ выполняются граничные условия: при $\omega \to 0$ и $\omega \to \infty$ АЧХ стремится к единице. Это означает, что фильтр пропускает как низкочастотные, так и высокочастотные составляющие сигнала без искажений, что полностью соответствует постановке задачи.

Во-вторых, при $\omega = \omega_0 = 5$ рад/с АЧХ всех кривых обращается в строгий ноль. Данная точка представляет собой центр полосы подавления, в которой фильтр полностью уничтожает входной сигнал. Глубина режекции не зависит от выбора $b_1$ и всегда является идеальной.

В-третьих, параметр $b_1$ оказывает определяющее влияние на ширину полосы подавления. При минимальном значении $b_1 = 0.1$ провал АЧХ является исключительно узким и резким: фильтр подавляет сигнал лишь в непосредственной окрестности частоты $\omega_0$, практически не затрагивая соседние частоты. По мере увеличения $b_1$ полоса подавления монотонно расширяется, а форма провала становится всё более пологой. При $b_1 = 1$ фильтр демонстрирует умеренную избирательность. При максимальном рассмотренном значении $b_1 = 10$ полоса подавления становится настолько широкой, что фильтр начинает существенно ослаблять сигналы в диапазоне частот, далёких от $\omega_0$, что может привести к нежелательным искажениям полезной составляющей.

Таким образом, параметр $b_1$ выполняет роль регулятора добротности режекторного фильтра: малые значения $b_1$ обеспечивают высокую избирательность и узкую полосу подавления, тогда как большие значения $b_1$ приводят к широкой, но менее селективной режекции. Выбор оптимального значения $b_1$ представляет собой компромисс между глубиной подавления целевой помехи и сохранностью полезного сигнала на соседних частотах.


\subsection{Исследование влияния параметра $b_1$}

В данном подразделе исследуется влияние параметра $b_1$ на эффективность режекторной фильтрации. Параметр $b_1$ определяет ширину полосы подавления фильтра. Амплитуда гармонической помехи принята равной $c = 2$, а её частота совпадает с частотой подавления фильтра: $d = \omega_0 = 5$ рад/с. Таким образом, помеха точно попадает в центр режекции.

\subsubsection{Случай узкой полосы подавления ($b_1 = 0.1$)}
При минимальном значении параметра $b_1 = 0.1$ фильтр обладает узкой полосой подавления.

До начала полезного импульса ($t < -17$) и после его окончания ($t > 27$) отфильтрованный сигнал представляет собой затухающие колебания на частоте $\omega_0 = 5$ рад/с с очень медленным декрементом затухания. Непосредственно на интервале действия прямоугольного импульса ($t \in [-17, 27]$) полезный сигнал также модулирован затухающими колебаниями той же частоты, амплитуда которых постепенно снижается по мере приближения к середине импульса. Форма полезного сигнала в целом сохраняется, однако накладывается выраженный колебательный звон фильтра.

В частотной области спектр зашумлённого сигнала $|\hat{u}(\omega)|$ содержит острый пик на частоте $\omega = 5$ рад/с, соответствующий гармонической помехе. Спектр отфильтрованного сигнала $|\hat{y}(\omega)|$ демонстрирует частичное подавление этого пика: его амплитуда существенно снижена по сравнению с исходной, однако не обращается в строгий ноль. Это объясняется тем, что спектр конечного по длительности синусоидального сигнала не является идеальной дельта-функцией, а имеет ненулевую ширину главного лепестка. Узкий провал АЧХ фильтра при $b_1 = 0.1$ не способен подавить весь спектр помехи целиком, пропуская её боковые спектральные составляющие. Спектр полезного сигнала практически не искажается, так как провал АЧХ слишком узок, чтобы затронуть частотные составляющие прямоугольного импульса.

Графики верификации подтверждают полное тождество результатов, полученных двумя независными методами. В частотной области модуль Фурье-образа отфильтрованного сигнала $|\hat{y}(\omega)|$ полностью совпадает с произведением $|W_2(i\omega) \cdot \hat{u}(\omega)|$. Это служит строгой численной верификацией теоремы о свёртке для данного вычислительного эксперимента.

На интервале действия прямоугольного импульса ($t \in [-17, 27]$) полезный сигнал модулирован колебаниями, амплитуда которых постепенно снижается по мере продвижения к середине импульса. После окончания импульса ($t > 27$) также присутствуют затухающие колебания, но их длительность заметно короче.

Это объясняется тем, что спектр конечного синусоидального сигнала имеет ненулевую ширину, и узкий провал АЧХ при $b_1 = 0.5$ не способен подавить все спектральные составляющие помехи. \subsubsection{Случай широкой полосы подавления ($b_1 = 5$)}

При $b_1 = 5$ полоса подавления фильтра становится достаточно широкой. Несмотря на это, фильтр демонстрирует высокую эффективность: гармоническая помеха на частоте $d = 5$ рад/с полностью подавлена, что видно по отсутствию пика в спектре отфильтрованного сигнала $|\hat{y}(\omega)|$ в окрестности $\omega = 5$ рад/с.

Во временной области фильтрованный сигнал хорошо воспроизводит форму исходного прямоугольного импульса. На переднем и заднем фронтах наблюдаются небольшие выбросы (перерегулирование), которые однако очень быстро затухают. На протяжении всего интервала действия импульса ($t \in [-17, 27]$) сигнал остаётся практически плоским на уровне $a = 4$, без заметных колебаний. \subsection{Выводы}
В ходе выполнения второго задания лабораторной работы был спроектирован и исследован режекторный полосовой фильтр второго порядка. Анализ условий задания позволил однозначно определить все параметры передаточной функции: $a_1 = 0$, $a_2 = \omega_0^2$, $b_2 = \omega_0^2$, $b_1 > 0$. Полученная передаточная функция $W_2(p) = \frac{p^2 + \omega_0^2}{p^2 + b_1p + \omega_0^2}$ описывает классический режекторный фильтр, подавляющий сигналы в узкой полосе вокруг частоты $\omega_0$ и пропускающий как низкие, так и высокие частоты.

Исследование влияния параметра $b_1$ на форму АЧХ выявило его роль как регулятора добротности фильтра. Малые значения $b_1$ формируют узкий и глубокий провал АЧХ, обеспечивая высокую избирательность, однако при этом фильтр становится чувствительным к малейшим расстройкам частоты помехи относительно $\omega_0$. Увеличение $b_1$ расширяет полосу подавления, делая фильтр более устойчивым к неточному знанию частоты помехи, но одновременно повышает риск искажения полезного сигнала, чьи спектральные составляющие могут попасть в зону режекции. Вычислительные эксперименты при точном совпадении $d = \omega_0 = 5$ рад/с показали, что даже при значительном расширении полосы подавления ($b_1 = 5$ и $b_1 = 10$) форма прямоугольного импульса сохраняется практически без искажений, поскольку основная энергия спектра полезного сигнала сосредоточена в главном части функции $\text{sinc}$ вблизи нулевой частоты, а на частоте $\omega_0 = 5$ рад/с Фурье-образ импульса уже мал.

Исследование влияния частоты помехи $d$ при фиксированном $b_1 = 1$ наглядно продемонстрировало главный принцип работы режекторного фильтра: его эффективность критически зависит от попадания частоты помехи в полосу подавления. При значительном расхождении частот ($d = 2$, $d = 4$, $d = 7$) фильтр практически не оказывает влияния на помеху, пропуская её без ослабления. При близком расхождении ($d = 4.9$, $d = 5.1$) наблюдается частичное подавление помехи, поскольку её частота попадает на склон провала АЧХ. Полное подавление достигается только при точном совпадении $d = \omega_0$. Это подчёркивает фундаментальное ограничение режекторных фильтров: они применимы лишь в тех случаях, когда частота помехи известна заранее и остаётся стабильной во времени.

Отдельно необходимо отметить полную математическую эквивалентность временного и частотного подходов к анализу системы. Идеальное совпадение результатов, полученных путём численного интегрирования дифференциальных уравнений во временной области с помощью функции \texttt{lsim}, и данных, вычисленных через перемножение спектральных плотностей с последующим обратным унитарным преобразованием Фурье, служит строгой численной верификацией теоремы о свёртке для всех рассмотренных комбинаций параметров. Это подтверждает корректность как математического аппарата, так и реализованных вычислительных процедур, включая расчёт ненулевых начальных условий на левой границе сетки моделирования.

В целом, режекторный полосовой фильтр представляет собой эффективный инструмент для подавления узкополосных гармонических помех с известной частотой. Его главное преимущество перед фильтром низких частот заключается в способности сохранять высокочастотные составляющие полезного сигнала, которые неизбежно теряются при низкочастотной фильтрации. Однако применение режекторного фильтра требует точного знания частоты подавления и тщательного выбора параметра $b_1$, балансирующего между избирательностью фильтра и допустимым уровнем искажений полезного сигнала.
